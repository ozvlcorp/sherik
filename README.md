# SHERIK

Практическая платформа о партнёрстве и исламских финансах на русском и узбекском языках.

## Возможности

- 12 тем базы знаний со ссылками на источники.
- Диагностика и сравнение ответов двух партнёров.
- 7 калькуляторов: прибыль и убыток, авансы, P&L, новые вложения, неденежный вклад, реинвестирование, выход.
- Разбор ситуаций и план действий.
- Проекты документов, экспорт в Word, Excel, HTML и печать в PDF.
- Локальные проекты, история расчётов и резервные копии JSON.

## Использование

Откройте `index.html` в браузере или опубликованный сайт GitHub Pages. Сборка и установка зависимостей не нужны. Интерфейс, шрифты и логика находятся в одном HTML-файле.

Данные сохраняются только в браузере пользователя. Для переноса на другое устройство или новый адрес сайта используйте экспорт и импорт JSON. Автоматической облачной синхронизации нет.

## GitHub Pages

Источник публикации: ветка `main`, папка `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll.

## Источники и оформление

Основные финансовые источники: Shariah Board of the State Bank of Pakistan и International Islamic Fiqh Academy. Точные ссылки и границы применимости доступны в разделе «Источники». Документы формируются как предварительные проекты для согласования.

Визуальный референс: [Al-Maktaba Al-Shamela — UX Audit & Interface Redesign](https://www.behance.net/gallery/252232267/Al-Maktaba-Al-Shamela-UX-Audit-Interface-Redesign). Орнаменты и обложки созданы средствами HTML/CSS/SVG.

Manrope и Lora распространяются по SIL Open Font License. Тексты лицензий находятся в `FONT-LICENSES.txt` и встроены в HTML.
